# Python Learning Examples

This repository contains simple Python example scripts organized by topic.

## Contents

- `conditional-and-lists/` - examples of `if/else` statements and list operations
- `dictionary/` - examples working with Python dictionaries
- `loops/` - examples using loops
- `tuples/` - tuple examples
- `type-casting/` - examples of converting between data types

## Usage

Run any script with Python from the command line, for example:

```bash
python dictionary/03_dictionary.py
```

## Notes

These scripts are intended for learning Python fundamentals and practicing basic syntax.
